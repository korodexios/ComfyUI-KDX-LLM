# KDX LLM — V3 Compatibility

## Background

ComfyUI is migrating from the V1 node schema (`NODE_CLASS_MAPPINGS`) to the
V3 schema (`io.ComfyNode` + `define_schema()` + `comfy_entrypoint()`). The
V3 API (`comfy_api` v0_0_2) is the first (and only) version and "more changes
will be made to it without warning" (official docs).

**Decision:** V1 is the primary path (works on all ComfyUI versions). V3 is
dormant behind an env-gate. Do **not** drop V1.

## Env Gate

**File:** `__init__.py`

```python
_KDX_LLM_V3 = os.environ.get("KDX_LLM_V3", "").strip().lower() in ("1", "true", "yes")

if _KDX_LLM_V3:
    # V3 mode: do NOT define NODE_CLASS_MAPPINGS
    # ComfyUI will use comfy_entrypoint() instead
    from .v3_adapter import comfy_entrypoint
else:
    # V1 mode (default): define NODE_CLASS_MAPPINGS (14 display nodes; 15 mappings incl. legacy alias)
    from .client import NODE_CLASS_MAPPINGS as CLIENT_NODES
    ...
    NODE_CLASS_MAPPINGS = {**CLIENT_NODES, **CHAT_NODES, ...}
```

| `KDX_LLM_V3` | Registration path | Node count |
|--------------|-------------------|------------|
| unset / `0` / `false` | V1 (`NODE_CLASS_MAPPINGS`) | 14 display nodes (15 mappings incl. legacy alias) |
| `1` / `true` / `yes` | V3 (`comfy_entrypoint`) | Chat + Session custom adapters, plus generic adapters for remaining V1 nodes where the installed `comfy_api` supports them |

**Default is V1.** Production runs V1. V3 is for dev/test only.

## V3 Adapter

**File:** `v3_adapter.py`

### `KDXLLMV3Extension`

```python
class KDXLLMV3Extension(ComfyExtension):
    def get_node_list(self):
        return [KDX_LLM_ChatV3, KDX_LLM_SessionV3, *generic_v3_wrappers]
```

Inherits from `comfy_api.extension.ComfyExtension` (falls back to `object`
if `comfy_api` is not installed). ComfyUI checks `isinstance(result,
ComfyExtension)` — the subclass is required.

### `comfy_entrypoint()`

```python
def comfy_entrypoint():
    return KDXLLMV3Extension()
```

Called by ComfyUI when `NODE_CLASS_MAPPINGS` is not defined.

### V3 Node Schemas

Each V3 node uses `io.ComfyNode` with `define_schema()`:

```python
class KDX_LLM_ChatV3(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="KDX_LLM_Chat",
            display_name="💬 KDX • LLM Chat",
            category="KDX/LLM",
            inputs=[
                io.String.Input("prompt", default="", multiline=True),
                io.Combo.Input("model_preset", options=list(MODEL_PRESETS.keys()), default="generic"),
                io.Custom.Input("KDX_LLM_CLIENT", "client", optional=True),
                io.Custom.Input("KDX_LLM_OPTIONS", "thinking_sampling", optional=True),
                ...
                io.Combo.Input("json_mode", options=["auto", "on", "off"], default="auto"),
                io.Int.Input("n_ctx", default=4096, min=512, max=262144, advanced=True),
            ],
            outputs=[
                io.String.Output("response"),
                io.String.Output("thinking"),
                io.String.Output("json"),
                io.String.Output("raw"),
                io.String.Output("model_used"),
                io.String.Output("profile_key"),
                io.String.Output("profile_json"),
                io.String.Output("request_info"),
                io.Any.Output("response_obj"),
                io.Custom.Output("KDX_LLM_SESSION", "session"),
            ],
        )

    @classmethod
    def fingerprint_inputs(cls, inputs):
        return canonical_hash(build_fingerprint_key(inputs))

    @classmethod
    def execute(cls, **kwargs):
        # Delegates to the V1 KDX_LLM_Chat.run()
        ...
```

### V3-Specific Features

| Feature | V1 | V3 |
|---------|----|----|
| `advanced=True` | Hidden via JS (`kdx_llm.js`) | Native ComfyUI toggle |
| `force_input=True` | N/A | On TOOLS, MEDIA, SAMPLING, PROFILE sockets |
| `not_idempotent=True` | N/A | On Chat (two identical nodes don't share cache) |
| `fingerprint_inputs` | `IS_CHANGED` (same hash) | `fingerprint_inputs` (same hash) |
| Custom types | `io.Custom` strings | `io.Custom("KDX_LLM_CLIENT")` etc. |

### Shared Logic

Both V1 and V3 nodes delegate to the same `kdx_core/` functions:
- `build_chat_payload()` — sampling merge
- `build_fingerprint_key()` + `canonical_hash()` — cache keys
- `KDXLLMSession` — session objects
- `KDXLLMResponse` — structured response

The V3 `execute()` is a thin wrapper around the V1 `run()`.

## Testing V3

```bash
# Run with V3 mode
KDX_LLM_V3=1 python main.py

# Verify node registration
curl -s http://localhost:8188/object_info | python3 -m json.tool | grep KDX
```

**Live check:** `tests/test_v3_schema.py`, run with ComfyUI's Python from the ComfyUI folder
(`python custom_nodes/ComfyUI-KDX-LLM/tests/test_v3_schema.py`). It checks the schema, output types,
`not_idempotent`, `fingerprint_inputs` and that V1 and V3 compute the same hash.

## Migration Path (Future)

When `comfy_api` v0_0_2 stabilizes:
1. Remove the env-gate — V3 becomes the default
2. Keep V1 as a fallback for older ComfyUI versions
3. Add integration tests (real ComfyUI runtime)
4. Deprecate V1 STRING outputs (slots 0–7) in favor of `KDXLLMResponse`
5. Remove V1 registration in 3.x
